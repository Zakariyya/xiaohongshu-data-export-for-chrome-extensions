# 小红书数据一键导出

一个 **Chrome 插件**，自动导出小红书创作服务平台的数据，不用手动切换每个选项卡、逐个下载 Excel。每次导出都会按日期时间整理到独立文件夹。

## 能导出什么？

- **账号概览**：观看、互动、涨粉、发布数据，分别导出近 7 日和近 30 日，共 **8 份 Excel**。
- **内容分析**：导出 **笔记列表明细**，共 **1 份 Excel**，尽量选择平台允许的最大日期范围。
- **自动归档**：本轮文件、导出记录和运行日志保存在同一个文件夹。

## 怎么安装？

1. 点击本仓库 **Code → Download ZIP**，下载并解压。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。

## 怎么用？

1. 在 Chrome 中登录 [小红书创作服务平台](https://creator.xiaohongshu.com/)。
2. 点击浏览器工具栏中的插件图标。
3. 选择 **开始批量导出（9 项）**，或者 **仅导出笔记列表明细**。
4. 保持导出控制台打开，等待完成。文件保存在 Chrome 默认下载目录下：

```text
小红书数据导出/
└── 2026-10-26_20-18-06-301/
    ├── 观看数据_近7日.xlsx
    ├── 观看数据_近30日.xlsx
    ├── ...其他 Excel
    ├── 内容分析_笔记列表明细_....xlsx
    ├── 导出结果清单.json
    ├── 导出记录.txt
    └── 执行日志.txt
```

## 注意

- **当前仓库版本为 V1.3**：如果笔记日期未能自动选到近半年，插件会提示手动调整。
- 笔记明细受小红书后台可查询日期范围及导出条数限制，**不等于账号全部历史笔记**。
- 如果连续下载被 Chrome 阻止，可在 `chrome://settings/content/automaticDownloads` 中允许小红书网站自动下载多个文件。
