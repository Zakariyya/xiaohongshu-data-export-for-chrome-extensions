# 小红书数据一键导出

一个 **Chrome 插件**，自动导出小红书创作服务平台的数据，不用手动切换每个选项卡、逐个下载 Excel。每次导出都会按日期时间整理到独立文件夹。

## 能导出什么？

- **账号概览**：观看、互动、涨粉、发布数据，分别导出近 7 日和近 30 日，共 **8 份 Excel**。
- **内容分析**：导出 **笔记列表明细**，共 **1 份 Excel**，自动尝试选择平台允许的最大日期范围（通常近半年），并核验选中的起止日期。
- **自动归档**：本轮文件、导出记录和运行日志保存在同一个文件夹。

## 怎么安装？

1. 点击本仓库 **Code → Download ZIP**，下载并解压。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 `manifest.json` 的文件夹。

## 怎么用？

1. 在 Chrome 中登录 [小红书创作服务平台](https://creator.xiaohongshu.com/)。
2. 点击浏览器工具栏中的插件图标。
3. 选择 **开始批量导出（9 项）**，或者 **仅导出笔记列表明细**。
4. 保持导出控制台打开，等待完成。文件保存在 Chrome 默认下载目录下：

```text
小红书数据导出/
└── 2026-10-26_20-18-06-301/
    ├── 观看数据_近7日.xlsx
    ├── 观看数据_近30日.xlsx
    ├── ...其他 Excel
    ├── 内容分析_笔记列表明细_....xlsx
    ├── 导出结果清单.json
    ├── 导出记录.txt
    └── 执行日志.txt
```

## 定时全量导出

在助手页面的「定时全量导出」中开启开关，选择「每隔 X 小时」或「每天固定时间」，点击保存即可。首次倒计时从保存时开始，之后从全部导出成功时重新计算；每天模式使用电脑本地时间。页面显示下次执行时间及上次自动导出的结果。

- 倒计时模式遇到断网、超时或未全部完成，每次结束后等待 5 分钟重试，直到全部成功；重试会重新导出全部 9 项，部分已成功的文件可能重复下载。界面显示等待重试时间。
- 使用 Chrome 后台定时器，无需保持助手页面打开；到点不会打开助手或抢焦点。
- 为操作网页导出按钮，会临时创建一个不激活的小红书标签页，结束后自动关闭。请勿手动操作此标签页。
- 每轮导出全部 9 项，沿用日期时间文件夹。已有手动或自动导出运行时跳过本轮，避免重复下载。
- Chrome 必须运行、电脑保持唤醒、账号已登录。恢复后错过的计划最多补执行一次，不累计补跑；浏览器或扩展重启导致的半途任务会标记中断；倒计时模式恢复后等待 5 分钟重试，每天模式仍按原计划执行。
- 自动任务遇到登录或下载异常只记录失败，不弹出人工接力窗口。手动模式仍支持人工接力。
- 尽量静默下载：在 `chrome://settings/downloads` 关闭「下载前询问每个文件的保存位置」，并允许小红书连续自动下载。插件不会更改全局下载设置，也无法保证浏览器完全不显示下载提示。
- 关闭定时开关并保存会删除定时器，不会中断已开始的任务。同一扩展始终只使用一个固定名称的导出定时器，更新和重新加载不会累积。卸载后由 Chrome 清理；不要同时加载多个独立副本。

更新方法：覆盖原文件夹，在 `chrome://extensions` 点击原扩展的「重新加载」，然后刷新已打开的助手页面；无需另装一份。

## 开发验证

运行 `node --test --test-isolation=none tests/*.test.cjs`（Node 24）。测试使用模拟 Chrome API 验证计划、后台执行与异常处理，不代表真实账号下载通过。实际静默下载还需在已登录的 Chrome 中验收。

## 注意

- 插件会自动尝试日期快捷选项、日期输入框或日历选择。如果无法确认目标范围，会停止笔记明细导出并生成诊断记录，不会把较短范围冒充全量。
- 笔记明细受小红书后台可查询日期范围及导出条数限制，**不等于账号全部历史笔记**。
- 如果连续下载被 Chrome 阻止，可在 `chrome://settings/content/automaticDownloads` 中允许小红书网站自动下载多个文件。
