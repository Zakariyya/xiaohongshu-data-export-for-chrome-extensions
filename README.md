# 小红书数据一键导出助手

> 在日常使用的 Chrome 浏览器中，批量导出小红书创作服务平台的数据，并按每次运行时间自动整理到独立文件夹。

**无需安装桌面程序，无需提供账号密码。** 使用 Chrome 中已经登录的小红书创作服务平台页面，通过网页上的「导出数据」功能下载 Excel。

> [!IMPORTANT]
> 本仓库当前代码的版本为 **v1.3.0**，以仓库内的 ```manifest.json``` 为准。本文介绍的是该版本实际实现的功能；如果日期选择器没有提供兼容的快捷选项，**仍可能需要手动选择近半年**。这不是小红书官方插件。

## 为什么做这个工具？

在小红书创作服务平台中，观看、互动、涨粉、发布等数据分散在不同选项卡，还要分别选择近 7 日、近 30 日；逐篇笔记的数据又位于「内容分析」页面。

手动操作不仅繁琐，下载后的多个 Excel 也容易混在一起。这个插件将**切换栏目 → 选择时间 → 点击导出 → 检查下载 → 按日期归档**串联起来，方便周期性留存数据、复盘账号表现。

## 功能概览

| 功能 | 说明 |
| --- | --- |
| 批量导出账号数据 | 观看数据、互动数据、涨粉数据、发布数据 |
| 自动切换统计周期 | 上述每个栏目分别导出近 7 日和近 30 日，共 **8 份** |
| 导出笔记列表明细 | 进入「内容分析」，导出逐篇笔记数据，共 **1 份** |
| 一键运行两种模式 | **完整批量导出（9 项）** / **仅导出笔记列表明细（1 项）** |
| 自动归档 | 每轮运行在 Chrome 默认下载位置创建独立时间文件夹 |
| 下载检查与异常处理 | 检测下载是否创建、是否完成，支持失败重试、跳过和原网页人工点击接力 |
| 执行记录 | 输出结果清单、导出记录及运行日志，便于核对和排错 |
| 沿用现有登录状态 | 使用日常 Chrome 中的小红书登录会话，不启动独立浏览器用户配置 |

**完整批量导出 = 4 个数据栏目 × 2 个时间范围 + 1 份笔记明细，共 9 个任务。**

## 安装

适用于 **Chrome 114 或更高版本的桌面浏览器**，在 Windows 10 上无需额外安装 Python、Node.js 或其他运行环境。

1. 在本仓库页面点击 **Code → Download ZIP**，解压到一个**固定位置**（后续不要随意移动或删除该文件夹）。
2. 在 Chrome 地址栏打开 ```chrome://extensions```。
3. 开启右上角 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择包含 ```manifest.json``` 的仓库文件夹。
5. 将「小红书数据一键导出助手」固定到浏览器工具栏，便于以后使用。

也可以使用 Git：

```bash
git clone https://github.com/Zakariyya/xiaohongshu-data-export-for-chrome-extensions.git
```

然后在 ```chrome://extensions``` 加载克隆下来的仓库目录。

> 本项目目前采用**开发者模式加载本地扩展**的安装方式；不需要运行 EXE，也不需要将小红书的 Cookie 或密码导入插件。

## 使用方法

1. 在日常 Chrome 中打开 [小红书创作服务平台](https://creator.xiaohongshu.com/) 并登录。
2. 点击 Chrome 工具栏中的插件图标，打开导出控制台。
3. 选择：
   - **开始批量导出（9 项）**：依次导出 8 项账号概览数据和 1 项笔记列表明细。
   - **仅导出笔记列表明细**：适合补导或重新导出笔记数据，不重复执行前 8 项。
4. 保持**导出控制台**打开，并尽量不要手动操作正在由插件控制的小红书标签页。
5. 执行完成后，使用界面的 **打开下载文件夹** 查看本轮文件和日志。

### 关于笔记列表明细的日期范围

插件会检查「内容分析 → 笔记数据」的日期区间，尝试使用网页提供的「近半年」等快捷选项。

**当前仓库 v1.3.0 的实际行为：**

- 如果检测到大约半年（代码以 **165 天**为判断门槛），会继续导出。
- 如果自动选择不成功，会弹窗提示用户在**原小红书页面**调整日期范围，再返回插件继续。
- 也可以明确选择按当前较短范围导出；此时文件名会包含 ```仅当前范围_非全量```，避免误认为覆盖全部笔记。
- **通过 165 天检查，不代表精确验证了平台所允许的最早日期**；应以最终 Excel 的日期与行数为准。

> [!WARNING]
> 平台页面通常仅支持查询**近半年发布的笔记**，此前导出的官方 Excel 还提示**最多导出排序后的前 1000 条笔记**。因此「笔记列表明细」不保证包含账号全部历史内容。即使 9 个任务全部成功，仍应核对实际数据范围。

## 导出结果示例

文件会保存到 Chrome **当前默认下载目录**下面，而不是扩展安装目录：

```text
下载内容/
└── 小红书数据导出/
    └── 2026-10-26_20-18-06-301/         # 示例：本轮启动时间
        ├── 观看数据_近7日.xlsx
        ├── 观看数据_近30日.xlsx
        ├── 互动数据_近7日.xlsx
        ├── 互动数据_近30日.xlsx
        ├── 涨粉数据_近7日.xlsx
        ├── 涨粉数据_近30日.xlsx
        ├── 发布数据_近7日.xlsx
        ├── 发布数据_近30日.xlsx
        ├── 内容分析_笔记列表明细_平台最大可选范围_日期范围.xlsx
        ├── 导出结果清单.json
        ├── 导出记录.txt
        └── 执行日志.txt
```

以上是**结构示例**。笔记明细的实际文件名会包含真实起止日期，具体文件数则取决于成功的任务数量；中断、失败或只导出笔记明细时，不会凭空产生未完成的 Excel。

每次运行都会创建新的时间文件夹，不会覆盖上次运行结果。单项失败时，可通过日志和结果清单定位原因。

## 常见问题

<details>
<summary><strong>点击导出后没有出现文件，或一直提示下载未启动？</strong></summary>

1. 在 Chrome 地址栏打开 ```chrome://settings/content/automaticDownloads```。
2. 检查 ```creator.xiaohongshu.com``` 是否允许连续下载多个文件。
3. 查看 Chrome 下载记录，确认是否被浏览器拦截或中断。
4. 插件若弹出异常提示，可先尝试**重新自动尝试本项**；必要时到小红书原网页手动点击「导出数据」，再让插件检查并接管归档。

浏览器、页面结构或平台策略变化均可能影响自动点击，并不代表已经成功下载。
</details>

<details>
<summary><strong>为什么插件没有自动选择最宽的笔记日期范围？</strong></summary>

仓库中的 v1.3.0 会优先尝试页面可识别的快捷日期选项，但并非所有小红书日期控件都能由当前逻辑自动操作。无法确认时会提示人工调整；不会直接把默认近 30 日称为全部笔记。
</details>

<details>
<summary><strong>为什么只导出了 8 个文件，缺少笔记列表明细？</strong></summary>

账号概览的 8 项和内容分析的 1 项属于两个页面。请检查控制台的第 9 项状态与 ```导出记录.txt```。可以使用 **仅导出笔记列表明细** 单独补导。
</details>

<details>
<summary><strong>为什么导出成功了，Excel 的笔记数量仍与账号发布总数不同？</strong></summary>

账号统计数据和内容分析笔记列表的时间范围、统计口径和平台可导出上限未必一致。请检查 Excel 的实际起止日期、行数、平台提示及筛选条件；**下载成功不等于数据全量**。
</details>

<details>
<summary><strong>更新源码后，Chrome 为什么仍在使用旧版？</strong></summary>

替换本地扩展文件后，打开 ```chrome://extensions```，找到插件并点击 **重新加载**，然后重新打开导出控制台。不要同时启用多个不同目录中的旧版本。
</details>

## 权限与隐私

插件使用 [Chrome Manifest V3](https://developer.chrome.com/docs/extensions/develop/migrate/what-is-mv3)，当前申请的权限如下：

| 权限 | 用途 |
| --- | --- |
| ```tabs``` | 查找、打开和切换小红书后台标签页 |
| ```scripting``` | 在小红书页面执行可见界面元素的定位、点击与状态读取 |
| ```downloads``` | 观察下载任务、重命名并归档导出文件 |
| ```storage``` | 保存当前导出任务及下载检查状态 |
| ```https://creator.xiaohongshu.com/*``` | 将页面操作限定在小红书创作服务平台 |

按当前仓库源码，插件**不主动读取账号密码或 Cookie，不通过非公开 API 获取数据，也不包含将导出数据上传到第三方服务器的逻辑**。数据下载依赖已登录网页本身提供的导出功能，并保存到本机的 Chrome 下载目录。

插件需要检查浏览器下载事件，请在使用期间避免同时触发其他无关文件下载，以免干扰当前任务的归档判断。

## 项目结构

```text
.
├── manifest.json       # 扩展入口、版本与权限
├── background.js       # 扩展后台：打开控制台、监听及归档下载
├── page-actions.js     # 小红书页面中的选项卡、日期与导出控件操作
├── dashboard.html      # 导出控制台
├── dashboard.css       # 控制台样式
├── dashboard.js        # 批量任务编排、下载检查、日志与异常处理
├── icons/              # 扩展图标
└── 安装及使用说明.txt
```

本项目为原生 JavaScript / HTML / CSS Chrome 扩展，未引入额外的前端构建步骤。修改代码后，在扩展管理页面点击**重新加载**即可本地验证。
